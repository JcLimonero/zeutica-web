# Zeutica redesign (look Praxisdienst, sin tienda)

Sitio corporativo B2B en Next.js 15 + React 19. Contenido 100% Zeutica (ES). Sin WooCommerce / carrito / precios.

## Cómo correr

```bash
cd zeutica-redesign
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Producción local:

```bash
npm run build && npm start
```

## Páginas

- `/` — Home
- `/productos` — Familias + listado informativo + marketplaces
- `/cotizaciones` — Formulario lead
- `/conocenos` — Nosotros
- `/atencion-al-cliente` — Contacto
- `/aviso-de-privacidad`, `/terminos` — Legales ES
